# Bundled webfonts

Self-hosted copies of the three typefaces the UI renders. Generated by
`scripts/vendor-fonts.mjs`; do not edit by hand.

## Why these are vendored

`src/styles/tailwind.css` used to `@import` the Google Fonts stylesheet over the
network. For a desktop app that promises to run entirely on your machine, that
was wrong in two ways:

- **Privacy.** Every launch made a request to `fonts.googleapis.com` and
  `fonts.gstatic.com`, disclosing the user's IP, User-Agent and launch timing to
  a third party — from the one application marketed on the premise that nothing
  leaves the device.
- **Offline.** With no network the request failed and the entire UI fell back to
  system fonts, which is immediately visible: Syne and JetBrains Mono carry the
  whole visual identity.

Only the `latin` and `latin-ext` subsets ship. The Greek, Cyrillic and
Vietnamese subsets Google serves would roughly triple the payload for glyphs
this interface never renders.

## Refreshing

```sh
node scripts/vendor-fonts.mjs
```

Re-downloads the current releases and regenerates `src/styles/fonts.css`.
