Ollama Setup
Ollama lets you run large language models locally with a single command. The models are downloaded and cached on disk — no cloud inference, no telemetry unless you opt in.
curl -fsSL https://ollama.ai/install.sh | sh ollama pull llama3.2 # 2.0 GB, very fast ollama pull mistral # 4.1 GB, better for longer context ollama run llama3.2 # starts local server on :11434
⬡ Primnox Integration

Set OLLAMA_BASE_URL=http://localhost:11434 in Primnox settings → Configure → LLM. Then switch the active model to ollama/llama3.2 for fully offline operation.

Privacy Architecture
What stays local
  • All conversation history — stored in SQLite at %APPDATA%\Primnox\chats.db
  • Notes and memories — ChromaDB vector store, local embeddings via fastembed
  • Activity feed — window tracking, app usage, never leaves your machine
  • Voice audio — processed in-process with Whisper, not uploaded anywhere
What can leave (with your control)
  • Chat messages → Groq API if using cloud model (disable: switch to Ollama)
  • Search queries → Brave Search API for Deep Research (disable: use offline mode)
Model Comparison
For daily use with Primnox, I recommend Llama 3.2 (3B) via Ollama — it handles conversational tasks quickly and fits in ~2GB RAM. Switch to Mistral 7B for longer notes or complex reasoning.
